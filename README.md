# 🎵 Musicium — Discord Music Bot & Mini App (Discord Activity)

Musicium — это мультиплатформенный музыкальный бот и интерактивная активность нового поколения (**Discord Activity / Mini App**) для серверов Discord.

Вместо текстовых команд Musicium объединяет серверного бота на Python с визуальным веб-интерфейсом: участники голосового канала запускают совместную сессию прямо в окне Discord (через Discord Embedded App SDK) или в браузере, управляя очередью, громкостью и обложками в реальном времени.

---

## ✨ Ключевые возможности

* **🎛 Интерактивный Mini App (Discord Activity):** Управление плеером прямо в окне Discord через встроенное веб-приложение с неоновым Glassmorphism-дизайном, анимированной виниловой пластинкой и спектрограммой.
* **⚡ Мгновенная синхронизация через WebSocket:** Любое действие (пауза, перемотка, добавление трека) синхронизируется между всеми слушателями за миллисекунды.
* **🌐 Мультипровайдерная музыка:**
  * **YouTube Music & YouTube** (умный фильтр миксов/радио-параметров, обход ограничений).
  * **SoundCloud** (полноразмерные обложки 500x500 через встроенный прокси-сервис).
  * **Яндекс.Музыка** (высокое качество потока, поддержка альбомов и плейлистов).
  * **Прямые аудиопотоки** (радиостанции и прямые URL).
* **🛡 Интеллектуальный Anti-Crash & Anti-Spam:**
  * Скользящее окно запросов (Rate Limiting).
  * Защита от спам-кликов и зацикливаний.
  * Автоматическая блокировка нарушителей с сохранением в PostgreSQL.
  * Панель инспекции и разблокировки в админ-меню.
* **⏱ Автоотключение при простое (Idle Watchdog):** Бот автоматически освобождает голосовой канал через 3 минуты неактивности или если канал опустел.
* **🔒 Полнофункциональная панель администратора:**
  * Мониторинг загрузки ОЗУ, пинга, статуса базы данных и сессий.
  * Управление активными голосовыми подключениями серверов (Leave/Play/Очередь).
  * Просмотр логов в реальном времени с фильтрацией.
  * Быстрая очистка кэша треков и синхронизация Discord слэш-команд.
  * Доступ к панели админа прямо из Mini App без блокировок iframe.

## 🛠 Технологический стек

* **Ядро:** Python 3.10+, `discord.py` v2.3+, `PyNaCl`, `davey`
* **Веб-сервер и API:** `aiohttp` (асинхронный HTTP & WebSocket сервер)
* **Аудио-пайплайн:** `yt-dlp`, `static-ffmpeg`, `yandex-music`, нативный Opus (`libopus`)
* **База данных:** PostgreSQL (`asyncpg`), пул соединений
* **Фронтенд:** Vanilla JavaScript (ES6+), Glassmorphism CSS, Discord Embedded App SDK

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/sosmula616-star/musicium.git
cd musicium
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта:
```env
BOT_TOKEN=your_discord_bot_token_here
CLIENT_ID=your_discord_client_id_here
CLIENT_SECRET=your_discord_client_secret_here
PUBLIC_KEY=your_discord_public_key_here
DATABASE_URL=postgresql://user:password@host:port/dbname
ADMIN_PASSWORD=your_secure_admin_password
PORT=3000
```

### 4. Запуск бота
```bash
python main.py
```
