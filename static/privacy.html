1. Введение и базовые принципы

Команда разработчиков Musicium Team («Мы», «Наш Сервис») с максимальной ответственностью относится к приватности и конфиденциальности данных каждого пользователя Discord.

Настоящая Политика конфиденциальности («Политика») разъясняет, какие технические данные обрабатываются при использовании бота «Musicium» и встроенного веб-приложения Discord Activity (Mini App), каким образом они защищены и на каких принципах строится их использование.

Фундаментальный принцип минимизации данных (Privacy by Design):
Мы собираем и обрабатываем исключительно минимально необходимый технический объем информации, без которого технически невозможно подключение бота к голосовому каналу, трансляция звука и отображение очереди воспроизведения.

2. Категории обрабатываемых технических данных

Сервис оперирует исключительно следующими общедоступными техническими метаданными платформы Discord:

  • Discord User ID (Идентификатор пользователя): публичный уникальный числовой идентификатор учетной записи Discord. Используется для привязки добавленного трека к автору запроса, отображения ника заказчика в очереди и обработки голосов в механизме пропуска (`vote_skip`).
  • Guild ID и Voice Channel ID (Идентификаторы сервера и голосового канала): технические номера, позволяющие Discord-клиенту бота подключиться к правильному голосовому каналу на конкретном сервере и адресовать WebSocket-события именно участникам данной гильдии.
  • Отображаемое имя (Display Name) и аватар: публичные элементы профиля пользователя, запрашиваемые локально через официальный протокол Discord Embedded App SDK для персонализации веб-интерфейса Mini App во время текущей сессии.
  • Служебные данные очереди (Play Queue & History): названия треков, ссылки на источники и продолжительность песен, находящихся в текущей очереди сервера. Хранятся исключительно в оперативной памяти процесса (In-Memory RAM).

  • Мы **НИ ПРИ КАКИХ ОБСТОЯТЕЛЬСТВАХ НЕ ПРОДАЕМ**, не сдаем в аренду и не передаем пользовательские технические данные коммерческим рекламным сетям или аналитическим брокерам данных.

4. Локальное хранилище браузера (LocalStorage)

Интерактивный плеер Mini App использует технологию веб-хранилища браузера (`localStorage`) исключительно для сохранения удобных для вас локальных клиентских настроек:

  • Выбранный уровень громкости воспроизведения (0–100%);
  • Последний выбранный режим повтора (off / track / queue);
  • Активный поисковый фильтр (YouTube, SoundCloud, Альбомы);
  • Кэшированные метаданные профиля Discord (для мгновенной отрисовки интерфейса без мигания при повторном открытии).

Эти параметры хранятся локально на вашем устройстве и никогда не отсылаются во внешние аналитические системы.

5. Сторонние интеграции и безопасность

Сервис взаимодействует со следующими внешними инфраструктурными поставщиками:

  • Discord Inc. (Discord API & Activities): инфраструктура авторизации и голосового протокола. Обработка данных подчиняется Политике конфиденциальности Discord.
  • YouTube (Google LLC) & SoundCloud Ltd.: общедоступные медиа-платформы, к публичным API которых отправляются текстовые поисковые запросы названий песен.

Все каналы передачи данных между клиентом, сервером и голосовыми шлюзами Discord защищены современным протоколом криптографического шифрования TLS/SSL (HTTPS и безопасные WebSockets WSS).

6. Права пользователей и удаление данных

Каждый пользователь и администратор сервера Discord обладает полным контролем:

  • Очистка очереди: нажатие кнопки «Очистить очередь» в веб-интерфейсе либо остановка плеера немедленно стирает список треков из оперативной памяти сервера;
  • Сброс локальных данных: вы можете в любой момент удалить локальные настройки, очистив кэш и хранилище браузера в настройках Discord;
  • Отзыв доступа: удаление бота с сервера немедленно прекращает любые процессы взаимодействия с данным сервером.
